Get Brixo

Brixo Player
Plays every game on the site. Press Play on any game page and Brixo Player opens and joins you in.
Brixo Studio
Where games get made: bricks, Rovik scripts, sounds, teams, tools, and a Publish button that puts your game on this site.

Downloads open with the public launch. Until then, Brixo is built from source. It takes a few minutes the first time:

  1. Install Rust from rustup.rs.
  2. In the Brixo folder, run cargo build --release --workspace
  3. Run target\release\brixo-player --register-protocol once, so Play buttons can open it.
  4. Open Studio with target\release\brixo-studio
